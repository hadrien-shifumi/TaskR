T Taskr maquettes haute fidélité — workspace Studio Nova

8 écrans · modern minimal · ShadCN-ready

Taskr — tracker de tickets minimaliste, piloté par le workspace.

Pas de sprints, pas de types d'issue, pas de workflow configurable : les statuts vivent au niveau workspace, la santé des projets est calculée, et tout est pensé pour être piloté par des humains ou des agents IA. Chaque maquette ci-dessous est interactive : dialogues, filtres, onglets, glisser-déposer.

01 · auth

Connexion / Inscription / Invitation

Guest layout centré. L'inscription crée le premier workspace avec les 4 statuts par défaut ; l'invité rejoint en tant que member.

 02 · home

Home — dashboard

Indicateurs du workspace, santé des projets, mes issues. Création d'issue minimale : un titre suffit.

 03 · projects

Projets — liste

Badge de projection + % terminé par projet. Archivés consultables ; suppression refusée si le projet contient des issues.

 04 · project

Projet — Health

Répartition par catégorie, retards, heures logguées / estimées, projection réalisé vs attendu à date.

 05 · issues

Issues — liste

Tous projets confondus, filtres fonctionnels (recherche, en cours, retard, urgentes, les miennes), création via dialog.

 06 · issue

Issue — détail

Statut libre, assignés multiples, labels à la volée, parent/enfants (erreur de cycle), temps, commentaires auteur-seuls.

 07 · settings

Settings — Statuts, Membres, Gabarits, Tokens

Réordonnancement par glisser-déposer, suppression protégée avec migration, bascule de rôle owner / member (lecture seule).

 08 · à venir

Gabarits d'issues & API tokens

Onglets planifiés : gabarits qui pré-remplissent sans contraindre, tokens pilotables par agents IA (valeur visible une seule fois).

Langage visuel

Catégories sémantiques de statut — la couleur vit sur la catégorie, jamais sur le nom libre

backlog in progress done cancelled

Priorités — 4 niveaux fixes

none low high urgent

Projections de santé — calculées, jamais saisies

On track At risk Late Pas de projection

Fondations modern minimal (Linear / Vercel) : neutres oklch, hairlines, ombres réservées aux dialogs et menus, numériques en mono tabulaire, identifiants opaques (ULID) affichés en mono. Les composants se mappent un-à-un sur ShadCN/ui — button, card, badge, dialog, table, tabs, select — avec les tokens Tailwind v4 (muted, destructive, etc.).
