Webhooks : retry avec backoff exponentiel

In Progress urgent due 14 oct. 2026 · dépassée

Description

Les webhooks Stripe en échec sont actuellement perdus. Il faut rejouer l'appel avec un backoff exponentiel plutôt que de compter sur la console Stripe.

Critères d'acceptation

  • 5 tentatives max, backoff 2^n secondes
  • Persistance des échecs dans la table webhook_events
  • Alerte Sentry au dernier échec

Voir la RFC interne : rfc/webhooks-retry.md.
